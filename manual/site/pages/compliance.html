ปฏิทินงาน (งานประจำ / Compliance)

ปฏิทินงานที่ต้องยื่นทุกเดือนของบริษัทหนึ่ง ๆ — ภ.พ.30 · ภ.ง.ด.1/3/53 · ประกันสังคม · ปิดบัญชี พร้อมวันครบกำหนดและสถานะรายงาน ใช้เป็นรายการเช็กว่าเดือนนี้ทำครบหรือยัง

ต่างจาก Dashboard อย่างไร

Dashboard = ดูภาพรวมและปิดงานเร็ว ๆ · ปฏิทินงาน = ที่ที่ สร้างงานของเดือน และ ตั้งค่าว่าบริษัทนี้ต้องยื่นอะไรบ้าง

1. การเข้าใช้งาน

  1. เลือกบริษัทลูกค้า ที่แถบด้านบน (หน้านี้ทำงานทีละบริษัท)
  2. เปิดเมนู ภาพรวม → ปฏิทินงาน
  3. เลือก 1 ใน 2 มุมมอง: ปฏิทินงาน หรือ ตั้งค่างานประจำ

2. มุมมอง “ปฏิทินงาน”

แถบด้านบน

ส่วนที่แสดงคำอธิบาย
บริษัทลูกค้าชื่อบริษัทที่กำลังดู (เปลี่ยนที่แถบเลือกบริษัทด้านบนสุด)
ปีปีที่ต้องการดู (ค.ศ.) พิมพ์เปลี่ยนได้
เกินกำหนด N รายการ ป้ายแดงมุมขวา — แสดงเมื่อมีงานเลยกำหนด นับรวมทั้งปี

กล่อง “ครบกำหนดใน 7 วัน”

กล่องสีเหลืองที่รวมงานใกล้ครบกำหนดไว้ให้ดูก่อน — แต่ละป้ายบอก งวด — ประเภทงาน (วันครบกำหนด) ถ้าไม่มีงานใกล้ครบกำหนด กล่องนี้จะไม่แสดง

การ์ด 12 เดือน

แต่ละการ์ดคือ 1 เดือน — คลิกเพื่อกรองตารางด้านล่างให้เหลือเฉพาะเดือนนั้น (คลิกซ้ำเพื่อยกเลิกการกรอง)

สิ่งที่เห็นบนการ์ดความหมาย
N รอจำนวนงานที่ยังไม่เสร็จของเดือนนั้น
N เกินกำหนดจำนวนงานที่เลยกำหนดแล้ว (ป้ายแดง และกรอบการ์ดเป็นสีแดง)
แถบความคืบหน้าสัดส่วนงานที่เสร็จแล้วของเดือนนั้น
ปุ่ม “สร้าง” แสดงบนการ์ดของเดือนที่ ยังไม่มีงาน — กดเพื่อให้ระบบสร้างรายการงานของเดือนนั้นตามที่ตั้งค่าไว้
งานไม่ได้ถูกสร้างเองอัตโนมัติ

ต้องกด สร้าง ของเดือนนั้นก่อน งานถึงจะปรากฏ — ถ้าเปิดปฏิทินแล้วว่างเปล่าทั้งปี แปลว่ายังไม่เคยสร้างงานให้บริษัทนี้ ไม่ใช่ว่าไม่มีงานต้องยื่น

ตารางรายการงานทั้งปี

คอลัมน์ความหมาย
เดือนเดือนของงาน (กดหัวคอลัมน์เพื่อเรียงได้)
ประเภทงานภ.พ.30 (VAT) · ภ.ง.ด.1 · ภ.ง.ด.3 · ภ.ง.ด.53 · ประกันสังคม · ปิดบัญชี
ครบกำหนดวันครบกำหนดยื่น — เลยกำหนดแล้วจะเป็นตัวหนาสีแดงพร้อมสัญลักษณ์ ⚠
สถานะดูตารางสถานะด้านล่าง
ผู้รับผิดชอบ เลือกได้จากตารางโดยตรง — รายชื่อคือผู้ใช้ที่มีสิทธิ์เข้าถึงบริษัทนี้ (ค่าตั้งต้นมาจาก “เจ้าหน้าที่บัญชีที่รับผิดชอบประจำ” ที่ตั้งไว้ใน ข้อมูลลูกค้า)
หลักฐาน ปุ่มแนบแบบที่ยื่น/ใบเสร็จของงวดนั้น — เขียว “N ไฟล์” = แนบแล้ว · เหลือง “+ ต้องแนบ” = ยังไม่แนบและงานนี้บังคับ · เทา “+ แนบ” = แนบได้แต่ไม่บังคับ
หมายเหตุบันทึกเพิ่มเติมของงานนั้น
ปุ่ม เริ่ม / เสร็จเปลี่ยนสถานะงานได้ทันทีจากตาราง
สถานะความหมาย
รอดำเนินการยังไม่เริ่มทำ
กำลังดำเนินการเริ่มทำแล้ว
เสร็จสิ้นยื่นเรียบร้อยแล้ว
เกินกำหนดเลยวันครบกำหนดและยังไม่เสร็จ

กดปุ่ม ส่งออก มุมขวาบนของตารางเพื่อบันทึกรายการงานทั้งปีเป็น Excel / CSV / PDF

3. มอบหมายผู้รับผิดชอบ

เลือกชื่อในคอลัมน์ ผู้รับผิดชอบ ได้ทันทีจากตาราง — บันทึกให้อัตโนมัติ ไม่ต้องกดปุ่มเพิ่ม

ไม่ต้องมอบหมายมือทุกเดือน

ตั้ง เจ้าหน้าที่บัญชีที่รับผิดชอบประจำ ไว้ที่ ข้อมูลลูกค้า ครั้งเดียว แล้วงานที่กด “สร้าง” ในเดือนถัด ๆ ไปจะถูกมอบหมายให้คนนั้นอัตโนมัติ — เปลี่ยนเป็นรายงาน/รายเดือนได้ที่ตารางนี้

งานที่มอบหมายแล้วไปโผล่ที่ไหน

กล่อง “งานของฉัน” บน Dashboard · แท็บ workboard และ ภาระงานรายคน ที่ งาน / มอบหมายงาน · และเป็นผู้รับอีเมลเตือนงานค้าง

4. หลักฐานการยื่น (บังคับก่อนปิดงาน)

กดปุ่มในคอลัมน์ หลักฐาน เพื่อแนบแบบที่ยื่นหรือใบเสร็จของงวดนั้น — ไฟล์จะถูกผูกกับงานงวดนั้นโดยตรง (ไม่ใช่แค่ผูกกับปีบัญชี) และไปปรากฏใน คลังเอกสาร / หลักฐาน ด้วย

ไม่มีหลักฐาน = ปิดงานไม่ได้

ถ้ากด เสร็จ โดยยังไม่แนบหลักฐาน ระบบจะปฏิเสธและขึ้นแถบเตือนสีเหลืองว่า “ต้องแนบหลักฐาน (แบบที่ยื่น/ใบเสร็จ) ของงาน … ก่อนจึงจะปิดงานเป็น เสร็จสิ้น ได้” — กันไม่ให้กดปิดงานทั้งที่ยังไม่ได้ยื่นจริง

เปิด/ปิดกฎได้รายประเภทงาน

ค่าเริ่มต้น: งานยื่นแบบ (ภ.พ.30 · ภ.ง.ด.1/3/53 · ปกส.) = บังคับ · งานปิดบัญชีประจำเดือน = ไม่บังคับ (ไม่มีใบเสร็จให้แนบ) — ปรับได้ที่ “ตั้งค่างานประจำ” ทั้งระดับมาตรฐานและเฉพาะบริษัท

5. มุมมอง “ตั้งค่างานประจำ”

กำหนดว่าบริษัทนี้ต้องยื่นงานประเภทไหนบ้าง และครบกำหนดวันที่เท่าไร — ค่าเหล่านี้ถูกใช้ตอนกด “สร้างงานเดือนนี้”

รายการแบ่งเป็น 3 กลุ่มตามรอบของงาน ซึ่งกำหนดว่างานนั้นเกิดกี่ครั้งต่อปี:

รอบสร้างเมื่อไรงานในกลุ่มนี้
รายเดือน ทุกเดือนที่กด “สร้างงานเดือนนี้” ภ.พ.30 · ภ.ง.ด.1 · ภ.ง.ด.3 · ภ.ง.ด.53 · ประกันสังคม · ปิดบัญชีประจำเดือน
ครึ่งปี ปีละครั้ง — เดือนที่ครบครึ่งรอบบัญชี
(รอบปีปฏิทิน = มิ.ย.)		 ภ.ง.ด.51
รายปี ปีละครั้ง — เดือนสุดท้ายของรอบบัญชี
(รอบปีปฏิทิน = ธ.ค.)		 ภ.ง.ด.50 · งบการเงิน + สบช.3 · ภ.ง.ด.1ก · กท.20ก
ไม่มีปุ่มแยกสำหรับงานรายปี

ใช้ปุ่ม “สร้างงานเดือนนี้” ปุ่มเดิม — พอกดในเดือน มิ.ย. งานครึ่งปีจะขึ้นมาพร้อมงานรายเดือน และพอกดในเดือน ธ.ค. งานรายปีก็จะขึ้นมาเอง ไม่ต้องจำอะไรเพิ่ม

คอลัมน์ความหมาย
ประเภทงานงานประจำที่ระบบรองรับ — จัดกลุ่มตามรอบ (รายเดือน / ครึ่งปี / รายปี)
ใช้งาน ติ๊กถ้าบริษัทนี้ต้องยื่นงานนั้น — ปิดได้ เช่น บริษัทที่ไม่ได้จด VAT ก็ปิด ภ.พ.30 ทิ้ง
ครบกำหนดหลังสิ้นงวด สองช่อง: กี่เดือน หลังสิ้นงวด + วันที่ ของเดือนนั้น (ใส่ 0 = วันสุดท้ายของเดือน)
ปล่อยว่างทั้งคู่เพื่อใช้ค่ามาตรฐาน — ใต้ช่องมีบรรทัดสรุปบอกว่าจะได้วันไหนจริง ๆ
ตัวอย่าง: ภ.พ.30 = 1 เดือน วันที่ 15 → วันที่ 15 ของเดือนถัดไป
ต้องแนบหลักฐาน ติ๊กไว้ = ปิดงานเป็น “เสร็จสิ้น” ไม่ได้จนกว่าจะแนบแบบที่ยื่น/ใบเสร็จของงวดนั้น
ที่มาบอกว่าค่าที่ใช้อยู่มาจากค่ามาตรฐานกลาง หรือถูกตั้งเฉพาะบริษัทนี้
คืนค่ามาตรฐานลบค่าที่ตั้งเองทิ้ง กลับไปใช้ค่ากลาง
ตั้งค่า 2 ระดับ

ระบบมีค่ามาตรฐานกลางให้อยู่แล้ว หน้านี้ใช้ ปรับเฉพาะบริษัทที่ต่างจากมาตรฐาน — บริษัทส่วนใหญ่ไม่ต้องแตะเลย

เปลี่ยนแล้วมีผลกับงานที่สร้างใหม่เท่านั้น

งานของเดือนที่สร้างไปแล้วจะไม่เปลี่ยนตาม — ถ้าต้องการ ต้องลบงานเดือนนั้นแล้วสร้างใหม่

6. งานประจำแต่ละประเภทเชื่อมไปเมนูไหน

งานทำที่เมนู
ภ.พ.30 (VAT)ภาษีมูลค่าเพิ่ม
ภ.ง.ด.1เงินเดือน → ภ.ง.ด.1
ภ.ง.ด.3 / ภ.ง.ด.53หัก ณ ที่จ่าย
ประกันสังคมเงินเดือน → ประกันสังคม
ปิดบัญชีปิดรอบบัญชี

ภ.ง.ด.1กเงินเดือน → ภ.ง.ด.1ก
กท.20กเงินเดือน → ประกันสังคม

สำหรับบริษัทที่ใช้รอบปีปฏิทิน (ม.ค.–ธ.ค.) ระบบตั้งไว้ให้ตามกฎหมาย: ภ.ง.ด.51 สิ้น ส.ค. · ภ.ง.ด.50 150 วันหลังสิ้นรอบบัญชี (30 พ.ค.) · งบการเงิน สิ้น พ.ค. · ภ.ง.ด.1ก / กท.20ก สิ้น ก.พ.
บริษัทที่ใช้รอบบัญชีอื่นระบบเลื่อนให้อัตโนมัติ ยกเว้น ภ.ง.ด.1ก กับ กท.20ก ที่ยึดปีปฏิทินเสมอเพราะเป็นการสรุปค่าจ้าง ม.ค.–ธ.ค.

7. ปัญหาที่พบบ่อย

อาการสาเหตุและวิธีแก้
ขึ้น “ยังไม่มีรายการงาน” ยังไม่ได้สร้างงานของเดือนนั้น — กดปุ่ม “สร้าง” บนการ์ดเดือน
สร้างแล้วได้งานไม่ครบ / เกินที่ต้องยื่น ไปที่ “ตั้งค่างานประจำ” ติ๊กเปิด-ปิดประเภทงานให้ตรงกับบริษัทนี้ แล้วสร้างเดือนนั้นใหม่
วันครบกำหนดไม่ตรงกับที่ยื่นจริง ตั้งวันครบกำหนดเฉพาะบริษัทที่ “ตั้งค่างานประจำ” (เช่น ยื่นออนไลน์ได้ถึงวันที่ 15)
กด “เสร็จ” แล้วขึ้นแถบเหลืองว่าต้องแนบหลักฐาน เป็นกฎที่ตั้งใจ — แนบแบบที่ยื่น/ใบเสร็จที่ปุ่มคอลัมน์ “หลักฐาน” ก่อน หรือถ้างานประเภทนั้นไม่ควรบังคับ ให้ติ๊กออกที่ “ตั้งค่างานประจำ”
ช่องผู้รับผิดชอบไม่มีชื่อที่ต้องการ ผู้ใช้คนนั้นยังไม่ได้รับสิทธิ์เข้าถึงบริษัทนี้ — ตั้งที่ ผู้ใช้งานระบบ
สร้างงานเดือนใหม่แล้วไม่มีผู้รับผิดชอบ บริษัทนั้นยังไม่ได้ตั้ง “เจ้าหน้าที่บัญชีที่รับผิดชอบประจำ” ที่ ข้อมูลลูกค้า — งานที่สร้างไปแล้วยังต้องมอบหมายเองที่ตาราง
เห็นแต่ของบริษัทเดียว หน้านี้ทำงานรายบริษัท — ดูภาพรวมทุกบริษัทที่ Dashboard (ล้างการเลือกบริษัท) หรือที่แท็บ workboard ของ งาน / มอบหมายงาน
